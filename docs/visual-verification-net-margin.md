# التحقق البصري — صافي هامش الربح

تم التقاط معاينة RTL كاملة للوحة الرئيسية بعد تعديل نموذج البيانات المالية وقالب Excel. الواجهة ما زالت تعمل دون أخطاء ظاهرة، وتظهر لوحة الفروع والعدادات والتقارير بصورة متسقة. التحقق البصري للحقول المالية التفصيلية يحتاج فتح تبويب البيانات المالية من حساب مستخدم إداري، لكن فحص TypeScript و74 اختبار Vitest نجحا، وHMR أكد تحديث Home.tsx.

## نطاق التغيير

- إضافة حقلي مرتجعات المبيعات ومرتجعات التكلفة.
- عرض صافي المبيعات وصافي التكلفة وصافي هامش الربح.
- تحديث قالب Excel المالي ليشمل حقول المرتجعات.
- إعادة احتساب اللقطات المالية الحالية من القيم المحفوظة.
