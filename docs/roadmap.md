# خارطة الأولويات المعتمدة

## المسار الأول: النسخة السحابية الحالية

يستمر استخدام النسخة السحابية لتثبيت بيانات الفروع، وتجربة الصلاحيات، وإدخال الملفات التشغيلية الفعلية، ومراجعة التقارير مع الإدارة. ترتيب الأولوية هو: بيانات الفروع والحالات، ثم المستخدمون والأدوار، ثم استيراد المبيعات والمخزون والمشتريات والمصروفات وقائمة الدخل، ثم تجربة مدير المنطقة، ثم التقارير المقارنة والتصدير.

## المسار الثاني: التطبيق المحلي

لا يبدأ تحويل الإنتاج مباشرة. يبدأ العمل المحلي بعد اعتماد قالب البيانات واستلام عينات فعلية من الملفات، ثم بناء نسخة تجريبية للقراءة والمقارنة، ثم تجربة محدودة، ثم اعتماد تدريجي مع نسخ احتياطية واختبار استعادة.

## بند ينتظر بيانات المستخدم

حصر مصادر الملفات الفعلية وأسماء الأوراق والأعمدة والفترات المتاحة لا يمكن إنجازه بأمان من دون ملفات الشركة أو وصفها. بعد رفع عينة شهر واحد، تُطابق الأعمدة مع القالب دون تعديل الأرقام الأصلية أو اختلاق بيانات.
