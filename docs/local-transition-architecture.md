# معمارية الانتقال إلى تطبيق Windows المحلي

## الهدف

يوفر التطبيق المحلي تشغيلًا داخل شبكة الشركة دون الاعتماد على الإنترنت أثناء العمل اليومي، مع إبقاء النسخة السحابية الحالية مسارًا مستقلًا للمراجعة والتطوير إلى أن يتم اعتماد النسخة المحلية رسميًا.

## ما يمكن إعادة استخدامه من النظام الحالي

يمكن إعادة استخدام نموذج الأعمال الحالي، ومسارات الفروع والمناطق والصلاحيات، وشاشات لوحة المتابعة وملف الفرع، ووحدات الزيارات والجودة والصيانة والوثائق والإجراءات والطلبات، وقوالب التقارير والتصدير، واختبارات قواعد الصلاحيات والتحقق. أما Manus OAuth وHeartbeat والخدمات السحابية والتخزين السحابي فلا تُنقل كما هي إلى الوضع غير المتصل، بل تستبدل بمكونات محلية.

## المكونات المقترحة

| الطبقة | الاختيار الأولي | الملاحظة |
|---|---|---|
| واجهة المستخدم | React مع حزمة Desktop مثل Tauri أو Electron | إعادة استخدام معظم مكونات الواجهة الحالية |
| خادم التطبيق | خدمة محلية داخل جهاز الخادم أو جهاز مخصص في الشبكة | لا يعتمد على منفذ ثابت داخل الكود |
| قاعدة البيانات | PostgreSQL محلية على خادم الشبكة، أو SQLite في نموذج جهاز واحد | PostgreSQL أفضل لتعدد المستخدمين والفروع |
| المصادقة | حسابات محلية مع كلمات مرور مجزأة وصلاحيات أدوار | لا تستخدم OAuth السحابي أثناء عدم الاتصال |
| الملفات | مجلد ملفات محلي مضبوط الصلاحيات مع سجل metadata | لا تحفظ الملفات الكبيرة داخل جداول قاعدة البيانات |
| النسخ الاحتياطي | نسخة مشفرة دورية إلى مسار احتياطي محلي منفصل | اختبار الاستعادة إلزامي، وليس مجرد إنشاء الملف |
| التدقيق | سجل append-only للتغييرات الحساسة | يشمل المستخدم والوقت والسجل والقيم قبل/بعد |
| الاستيراد | Excel/CSV مع مرحلة معاينة ثم اعتماد | يمنع الكتابة قبل نجاح التحقق والمطابقة |

## نموذج التشغيل داخل الشبكة

يُثبت خادم التطبيق وقاعدة البيانات على جهاز مركزي داخل شبكة الشركة. يتصل المستخدمون من أجهزة Windows عبر المتصفح الداخلي أو عميل Desktop. لا تُفتح المنافذ خارج الشبكة المحلية، وتُدار الحسابات من داخل النظام. يجب توفير حساب مسؤول طوارئ محفوظ وفق سياسة الشركة، مع تغيير كلمة مروره عند التسليم.

## نموذج البيانات الموحد

يجب أن ترتبط كل حركة تشغيلية بالفترة والفرع والصنف عند الحاجة. الكيانات الأساسية هي: الفروع، المناطق، المستخدمون والأدوار، الأصناف والتصنيفات، المبيعات، المشتريات، حركة المخزون، المصروفات، قائمة الدخل، المرتجعات والخصومات، الزيارات، الجودة، الصيانة، الأصول، الوثائق، الإجراءات، الطلبات، عمليات الاستيراد، سجل التدقيق، والنسخ الاحتياطية.

للتعامل مع أكثر من 1,000 صنف وأكثر من 15 فرعًا، تستخدم المفاتيح الرقمية الداخلية مع رمز خارجي ثابت للصنف والفرع، ويُمنع الاعتماد على اسم الصنف كمفتاح. تُحفظ قيم الاستيراد الأصلية ونتيجة المطابقة ومعرف دفعة الاستيراد حتى يمكن إعادة تدقيق الأرقام.

## قالب Excel الشهري

يتكون القالب من أوراق: `تعليمات`، `الفروع`، `الأصناف`، `المبيعات`، `المشتريات`، `المخزون`، `المصروفات`، `قائمة_الدخل`، و`قاموس_القيم`. تحتوي كل ورقة تشغيلية على رمز الفرع والفترة ورمز الصنف عند الحاجة والقيم الرقمية ووصف المصدر. لا يعتمد القالب على أسماء عربية حرة لتحديد المفاتيح؛ يستخدم القوائم المرجعية والرموز.

تمر عملية الاستيراد بأربع مراحل: رفع الملف، قراءة الأعمدة والصفوف، عرض الأخطاء والتحذيرات مع رقم الصف، ثم اعتماد الدفعة بعد نجاح القواعد. تشمل القواعد منع الفترة غير الصحيحة، منع الفرع غير المعروف، منع الصنف غير المعروف، منع التكرار، والتحقق من الأرقام السالبة أو القيم غير المنطقية بحسب نوع الحركة.

## الأمن والنسخ الاحتياطي

تُخزن كلمات المرور باستخدام خوارزمية تجزئة قوية، وتُطبق أقل صلاحية على المستخدمين. تسجل عمليات الإنشاء والتعديل والحذف والاستيراد والاعتماد والتصدير. تُشفر النسخ الاحتياطية قبل كتابتها إلى القرص، ويُحفظ مفتاح الاستعادة وفق إجراء منفصل عن مجلد النسخ. يجب اختبار الاستعادة على جهاز غير الإنتاج بصفة دورية.

## خطة التنفيذ المرحلية

1. جرد ملفات النظام المالي ومصادر Excel الفعلية واعتماد قاموس الفروع والأصناف.
2. اعتماد نموذج البيانات وقالب Excel على عينة شهر واحد.
3. بناء الاستيراد والمعاينة والتدقيق دون تشغيل مزامنة تلقائية.
4. تشغيل نسخة محلية تجريبية للقراءة والمقارنة فقط.
5. تشغيل تجريبي محدود لمستخدمين محددين مع نسخ احتياطية واختبار استعادة.
6. اعتماد التشغيل المحلي تدريجيًا مع إبقاء السحابة كمرجع حتى انتهاء فترة المقارنة.

## قرارات تحتاج اعتمادًا قبل التنفيذ

يجب تحديد جهاز الخادم المحلي، عدد المستخدمين المتزامنين، نظام قاعدة البيانات المفضل، مسارات النسخ الاحتياطي، سياسة الاحتفاظ، ومصادر ملفات المبيعات والمخزون والمشتريات والمصروفات وقائمة الدخل. لا يُنصح بتحويل النسخة السحابية مباشرة إلى نسخة محلية قبل استلام هذه المدخلات.
