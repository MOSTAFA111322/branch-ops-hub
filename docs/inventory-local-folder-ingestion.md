# عقد استيراد حركة الأصناف من مجلد الشبكة المحلي

تستخدم النسخة السحابية رفع ملف Excel من داخل التطبيق، بينما تستخدم النسخة المحلية وكيلًا صغيرًا على جهاز الشركة لمراقبة مجلد محدد. لا تتم مراقبة المجلد من خادم السحابة ولا يُستخدم `setInterval` داخل التطبيق.

## العقد الموحد

يقرأ الوكيل الملفات ذات الامتدادات `.xlsx` و`.xls` و`.csv`، ثم يرسلها إلى نفس مسار المعاينة والاعتماد المستخدم في الواجهة. يجب أن يتضمن الطلب اسم الملف واسم الورقة وبصمة SHA-256 للملف، ويحتفظ الوكيل بنسخة أرشيفية محلية بعد نجاح الاعتماد.

## الأمان وكشف التكرار

يُمنع اعتماد الملف إذا كانت بصمته موجودة مسبقًا، أو إذا تكرر المفتاح المركب للسجل: الشهر، رمز الصنف، مركز التكلفة، والفرع. يجب أن يعمل الوكيل بحساب خدمة محدود الصلاحيات، وأن يكتب سجلًا محليًا للنجاح والفشل دون تخزين كلمات المرور داخل ملف الإعداد.

## الإعداد المقترح

```json
{
  "watchDirectory": "\\\\SERVER\\BranchOps\\Inventory",
  "archiveDirectory": "\\\\SERVER\\BranchOps\\Inventory\\archive",
  "failedDirectory": "\\\\SERVER\\BranchOps\\Inventory\\failed",
  "pollingMode": "filesystem-events-with-safe-retry",
  "retryWindowMinutes": 10
}
```

عند تنفيذ النسخة المحلية، يفضل استخدام خدمة Windows أو Scheduled Task لتشغيل الوكيل، مع إعادة المحاولة بعد اكتمال نسخ الملف وتسجيل كل عملية في سجل التدقيق. يظل تحليل البيانات وقواعد المطابقة وكشف التكرار في طبقة التطبيق المشتركة، لتجنب اختلاف النتائج بين السحابة والنسخة المحلية.
